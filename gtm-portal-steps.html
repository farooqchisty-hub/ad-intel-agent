Google Ads tracking: what we need from engineering

One code change on the portal. Marketing does the rest in Google Tag Manager.

Why

Our YouTube ads can't count signups or installs. The portal (dashboard.pushowl.io) doesn't load Google Tag Manager, so Google loses every visitor as soon as they reach the signup page. We checked the signup page in a real browser on 15 Oct: no Tag Manager, no Google tag, no dataLayer, no Google cookies.

Once the portal loads Tag Manager, marketing can set up all the tracking without more code changes.

Engineering

Step 1. Add Google Tag Manager to the portal Required

  • Container ID: GTM-W9BPQ9 (the same one pushowl.com uses).
  • Load it on every portal page, including https://dashboard.pushowl.io/onboarding-portal/sign-up.
  • The portal is a Next.js app with a pages folder, so the simplest way is to add this to pages/_app.js:
import { GoogleTagManager } from '@next/third-parties/google'

// inside the JSX that _app returns:
<GoogleTagManager gtmId="GTM-W9BPQ9" />
Next.js guide: Google Tag Manager Google's install guide
Engineering

Step 2. Tell us two URLs Required

  1. What is the URL right after someone finishes signing up?
  2. What is the URL right after someone connects their Shopify store?
If each of these has its own URL, you're done. We'll set up the tracking from those URLs ourselves.
Engineering

Step 3. Only if the URL doesn't change at those moments Maybe

Add one line at each moment:

// right after signup succeeds
window.dataLayer = window.dataLayer || [];
window.dataLayer.push({ event: 'owl_portal_signup' });

// right after the Shopify store is connected
window.dataLayer = window.dataLayer || [];
window.dataLayer.push({ event: 'owl_portal_connect_shopify' });
Don't put the user's email or other personal data in these lines.
How dataLayer works
Engineering

Step 4. Keep everything else as it is

Leave the existing backend events and the current tags as they are. We'll stop relying on the backend events for Google Ads ourselves.

How to check it works

  1. Open the signup page, open the browser console and type dataLayer. You should see entries that include gtm.js.
  2. Or use Google Tag Assistant, connect it to the signup page and check that GTM-W9BPQ9 shows up.

What marketing does after that No engineering work needed

  1. In Tag Manager, pass the ad click ID (gclid, gbraid, wbraid) and UTM tags from pushowl.com links to the portal.
  2. In Tag Manager, add the GA4 and Google Ads tags to the portal.
  3. Mark the signup and install events as key events in GA4 and import them into Google Ads.
  4. Ask a GA4 admin to turn on cross-domain tracking.
