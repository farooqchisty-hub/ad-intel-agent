Rules this plan addsBinding for every clone, every brand.

1. Density is never a reason to skip.Any proven static of a product we sell gets cloned. More lines means more parallel text jobs, not a refusal.
2. Right model for each job.Layout and scene, product swap, text, faces and colour are separate jobs, each done by the model that measures best at it.
3. Our product is placed, not imagined.The store's own photos of the chosen product are the reference; the result must match them (cut, seams, colour, construction).
4. Every line becomes ours.No source line survives. A line with no exact parallel gets another true site fact for the same job in the same place.
5. Fix, don't drop.Any failed check triggers its fixer and a re-check, up to 4 rounds, many attempts in parallel per round. Only a product we don't sell is refused.

The new pipelineStages run side by side wherever one doesn't need another's output.

Measure the ad→Plan copy (3 drafts at once)+Pick product photos+Colour plan→Base image (3 models at once)→Product swap+Text blocks (one job per block, in parallel)+Face→Gate→Fix what failed, re-gate (max 4)

A. Base image

  • Three models in parallel (category-aware: no gpt-image-2 for intimate wear on a body) redraw the layout, scene, colours, logo and the big headline.
  • The prompt no longer asks for every small line; small text blocks are handled in C.
  • The best base is chosen on layout, scene, palette and headline only.

B. Product swap

  • Crop around the measured product box (with margin), give the editor that crop plus 2 to 4 store photos of the chosen product in the chosen colour.
  • 2 models x 2 tries in parallel; each result judged against the store photo (cut, seams, waistband, construction, colour). Best one pasted back with a feathered mask.
  • Off-body packshots keep the existing exact composite (our real photo, cut out).

C. Text, block by block

  • Each measured text block (callout, caption, label, button) is cropped, scaled up so its type is large, and edited: "replace these words with these, keep font, weight, colour, alignment".
  • All blocks run in parallel. OCR reads each block back; a block that misreads is redone (another model, another try) without touching the rest.
  • Fallback for any block still wrong after its tries: our line set in code in the measured font, size and colour (the existing typesetter), so the words are exact.

D. Face

  • A person in the source is redrawn from our casting reference in the face box; never erased or blanked.

E. Gate

  • Same fail-closed checks, now read per block too: OCR per block crop (small text read at full size), product judged on the product crop against the store photo, palette on pixels, two judges on the whole ad.

The fix-and-recheck loopUp to 4 rounds; each round fixes only what failed, many attempts at once.

Failed checkFixer
A line missing, misspelt or still theirsRedo that text block (other model, other try); after 2 misses, typeset it in code
Product doesn't match the storeRedo the product swap with more photos and the judge's evidence
Competitor colour leftLocal recolour of the flagged surfaces
Extra or moved logo, layout driftLocal inpaint in that box; if wide, a new base
Face reused, erased or wrongRedo the face step
Garbled marks, defectsLocal inpaint of the box the judge names

Each round runs its fixes in parallel and re-gates once. The ad ships the moment every check passes; after round 4 it goes to the queue tile with what is still wrong.

Copy rules (planner)From the website only, nothing invented.

  • Every source line gets a line of ours with the same job (headline, benefit, callout, caption, label, button, price).
  • No exact parallel? Use another true fact of the same kind for that product: a feature for a feature, a benefit for a benefit, an occasion for an occasion. "Steel boning support" becomes one of our product's own features, such as "Seamless, no visible lines".
  • Callouts that point at a part of the product describe that part of ours.
  • Length: a line over its range is never a reason to drop the ad; parallel drafts aim for the range, and the text step fits type to the box.
  • Before/after captions, "wear it under" thumbnails, icon labels: all adapted to our product and the occasions our site names.
