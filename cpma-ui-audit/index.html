Command Center UI audit

CPMA web app (cpma-agent.pages.dev), 20 Oct 2026. Before = the live site before the fix, after = deployed version 178d782b, commit 075ac79. Same live data both times; screenshots taken headless with motion off.

What caused the empty space

The Parked column holds 19 cards (about 6,000 px tall) and sat off to the right of the board's sideways scroll. The board row took that column's height, so the columns you could see ended early and a screen-tall blank area followed before the charts. Now every column stops at about one screen and scrolls inside itself, so the page ends right after its content.

Also fixed
  • Work board: six equal columns (were 310 px busy and 190 px empty, so "Agent working" wrapped); empty columns are a short dashed drop zone; on phones an empty column is just its header row. A soft edge shows when more columns sit to the side.
  • Cards: the same footer on every card (links, then Move and Share), so cards line up; P3 cards had no grey edge or badge (the badge was invisible in light mode); a labelled confidence bar, hidden when there's no score.
  • KPI tiles: the first (green) tile was also picking up the page-hero style, so it had its own padding, corners and a bottom margin and sat shorter than its row; missing values read "n/a" instead of a lone dot; long text values (the BFCM offer) shrink; eight tiles fit one row (Economics had one orphan).
  • Wording: every Command Center number says its window ("Link CTR, since 20 Oct", "Creative pipeline, since 20 Oct", "Spend and cost per install, since 20 Oct"); Performance tiles say "30 days"; Goals tiles use "cost per install" like the rest; "Verdicts, 14 days", "spend, 30 days"; next run reads "09:00 IST tomorrow" in the deck, the board and the card view.
  • Formats: money is "$15", "$13.40" or "$0.0412", never "$13.4"; numbers always group the US way whatever the browser language; missing table values are "·" everywhere (BFCM mixed "n/a" and blanks).
  • Phones: the nav showed empty buttons (labels and icons were both hidden); "What the agent has learned" and "Agent log" were squeezed side by side.
  • Light mode: deck status dots and (i) icons were near invisible on the green deck.
  • One empty-state style, one segmented-control style (Campaigns / Ad sets / Ads now matches Meta / Google / Combined), status chips shaped like tags, toolbar buttons one size and one height with the filters, Alerts "not set" no longer wraps.
