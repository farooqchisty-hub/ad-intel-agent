Why: three breaks

1. Installs reach GA4, but almost none can be credited to an ad install attribution

Checked in GA4 (property "PushOwl - Prod - GA4", stream "PushOwl Shopify App Store | GA4", G-DKNC4CCQ2D): the Measurement Protocol API secret exists (created Sep 2023) and shopify_app_install is live: 2,112 installs in the last 28 days. By session channel: Unassigned 1,287 (61%), Direct 405 (19%), Organic Shopping 346 (16%), Referral 39, Organic Search 20, Cross-network (the Google Ads YouTube campaigns) 0, Paid Search 0.

The App Store sends the install server-side, and most installs can't be joined to the visit that came before them, so they land in Unassigned or Direct. The 18,541 YouTube-ad sessions in the same 28 days produced 0 Install-button clicks and 0 installs in GA4. So two things are true at once: Google can only ever see a small share of installs, and the YouTube traffic shows no install intent at all.

2. The ad click ID is dropped on the way to signup attribution

  • The YouTube campaigns land on pushowl.com/lp/email-marketing. Its "Get started" opens the portal with utm_* only: the gclid is dropped (tested with a test gclid).
  • The portal page dashboard.pushowl.io/onboarding-portal/sign-up loads no Google tag at all (no GA4, no Ads tag, no click-id cookie).
  • The owl_portal_* events come from a backend GA4 property. Server-side events without the visitor's GA client id and session can't be tied to the ad click, so GA4 credits them to direct/unassigned and Google Ads imports nothing.
  • No cross-domain measurement between pushowl.com, dashboard.pushowl.io and apps.shopify.com, so each hop starts a new session without the click.

3. Bidding goals are a mix of noise configuration

  • Account-level biddable goals include Page view, Add to cart (= the Install button click), Download ("Android installs (all other apps)"), Lead form and Default. Any campaign on account defaults optimises toward clicks and page loads, not installs.
  • The real install (owl_portal_connect_shopify) is secondary, so even when it fires, bidding ignores it.
  • Imports come from four GA4 properties (PushOwl - Prod, PushOwl <GA4>, Pushowl Dashboard Backend, two MagicFit) with duplicated purchase/signup actions. pushowl.com and the listing both run two GA4 tags (G-4MLSL4TZ89, G-DKNC4CCQ2D). MagicFit's mar26mfsignup was being credited to PushOwl YouTube campaigns.
  • Final URLs carry ad-hoc manual UTMs (utm_source=ytrow3...), so GA4 reports are fragmented.

The fix, in order

  1. Stop the leak (today, your call): pause the 4 YouTube Owl Portal campaigns, or set them to a goal that has data, until steps 2 to 5 are verified. They bid on a goal with zero data.
  2. Install tracking is already on (API secret set, 2,112 installs in GA4 in 28 days). No Partner Dashboard change needed. The work is attribution: steps 3 to 5.
  3. Make install the goal (Google Ads): one primary conversion, "App Install (GA4)". Set Page view, Add to cart (button click), Download (Android), Lead form and the MagicFit actions to secondary. Campaigns that send people to the listing bid on installs only.
  4. Keep the click attached: every landing page must forward gclid, gbraid, wbraid and the UTMs to apps.shopify.com and the portal. The BFCM page already does; /lp/email-marketing needs its Get started script to add them. In GA4, set cross-domain measurement (Configure your domains: pushowl.com, dashboard.pushowl.io, apps.shopify.com).
  5. Portal signups and installs (PushOwl eng): load the Google tag (GA4 + AW-11391594536) on the onboarding portal and fire owl_portal_signup / owl_portal_connect_shopify in the browser, or, if they stay backend, send the visitor's GA client id and session id with each event. Most robust: store the gclid at signup and upload owl_portal_connect_shopify to Google Ads as an offline conversion.
  6. Clean up: one GA4 property per site, hide duplicate imports, standard UTMs (utm_source=google&utm_medium=video&utm_campaign=..., auto-tagging stays on), remove BugHerd from the LPs.
  7. Relaunch: after 3 to 5 days of installs showing in Google Ads with the click attached, re-enable spend with Maximize conversions (or tCPA ~$25) on the install goal.
