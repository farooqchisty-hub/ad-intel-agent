1. The whole system on one page

Four signals reach Google Ads by three routes: GA4 import, a browser tag, and click-ID uploads through Segment. The click ID (gclid, else gbraid/wbraid) is what ties a signup or install back to the ad click.

  • Tools: Shopify Partner listing tracking, GA4, GA4 to Google Ads link.
  • Attribution: GA4 session with the click ID. It only credits the ad if the install happens in the same browser session that came from the ad.
  • Limit: most installs reach GA4 with no source (34 of 110 since 12 Nov). The Google tag's cross-domain list only covers pushowl.com, and changing it needs a tag admin.

  • Tools: Intercom (install truth until the Partner API exists), bfcm-dash Worker and D1, Segment HTTP API and Google Ads Conversions destination, Google Ads scheduled CSV upload.

9. Known gaps

  • Unattributed installs in GA4: about a third of installs arrive with no source. Fixing this needs a Google tag admin to add cross-domain linking (apps.shopify.com, dashboard.pushowl.io).
  • Portal ignores gbraid/wbraid: iOS app clicks often carry only these, so those signups can't be credited.
  • Matched installs don't steer bidding: Store install (import) is secondary on purpose. Making it primary would let bidding chase matched installs, but would change the goal mid-campaign.
  • Ad edits need a Google identity check: the Search ad URLs are overridden at keyword level. Any new keyword must get the App Store final URL, or it lands on the deal page.
  • PushOwlAppInstall events carry only the store subdomain, so portal installs are matched by email or shop through Intercom, not by event.
